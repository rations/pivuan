# Packages in the Pivuan image

The packages the image build asks for (board `rpi4b`, kernel branch `current`, Devuan excalibur, minimal image). apt adds their dependencies. Everything comes from the Devuan archive except the packages marked Pivuan, from the Pivuan apt repository.

Generated by `packages/update-lists.py` from rations/build `3d7f5a5`, rations/configng `efe6b0e` and the apt repository (gh-pages `a55ed9d`). Do not edit by hand.
